# GENERATE — LAKA Operating Playbook

**Status:** Implementation extension to the conversation’s six-mode architecture. This is a procedure to apply, not an already functioning software tool.

## Purpose

Create distinct candidate systems tied to a desired observable Outcome.

## Inputs

Actor, Scenario, baseline system sentence, desired and undesired Outcomes, available Resources, known Constraints, and a bounded evidence set.

## Procedure

1. Define the current Scenario and desired result before selecting a favored Tool.
2. Fill the Baseline across all ten internal variables; mark unknowns rather than inventing them.
3. Sweep relevant variables across the five change levels and rotate through the fourteen dynamic modifiers.
4. Look for underexplored, contradictory, overcomplicated, or weakly supported choices; an empty cell is not evidence of novelty.
5. Compose compatible transformations into concepts with explicit mechanisms and Outcomes. Three to seven transformations is a convenience, not a requirement.
6. Compare each concept with the baseline, a simpler alternative, and the no-change option.
7. Define a small test that could reject the strongest assumption; retain rejected concepts and their reasons.

## Output

Concept cards, coordinate references, proposed mechanisms, required Resources, Outcome metrics, trade-offs, evidence gaps, and first tests.

## Stop condition

Stop when the agreed search budget or coverage is reached and the selected concepts have testable assumptions. Do not equate volume of ideas with quality.

## Critical distinction

Novelty requires comparison with existing work; feasibility requires domain evidence; market desirability requires stakeholder evidence.

## Run template

```text
RUN LAKA
MODE: GENERATE
ON: [SYSTEM OR QUESTION]
FOR: [ACTOR]
IN: [SCENARIO]
FROM: [OBSERVED BASELINE]
TOWARD: [OBSERVABLE OUTCOME]
TIME HORIZON: [DATE RANGE OR EVENT SEQUENCE]
EVIDENCE: [SOURCES AND ASSUMPTIONS]
DEPTH: [QUICK SCAN | FOCUSED SWEEP | COMPLETE VOLUME]
```

Preserve the user-defined axes exactly. Track unknowns, not-applicable cells, and counterevidence. PI reference keys are in `../08_sources/SOURCE_NOTES.md`.
