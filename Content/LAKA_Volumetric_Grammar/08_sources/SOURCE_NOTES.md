## Source-derived ideas versus LAKA design

| Source book concept | How it informed this package | Boundary |
|---|---|---|
| Actors, Desires, Scenarios, Alternatives, Outcomes, Elements | Actor/Scenario context and outcome-first analysis | LAKA’s context envelope is a design choice, not an additional PI quotation. |
| Outcomes × seven Elements × fifteen Alternatives | Structured multidimensional descriptions | LAKA’s 5 × 10 × 14 volume is different and is not claimed by the book. |
| Single, Multiple, Continuous × Direct, Indirect, Stable, Make Stable, Return to Stable | Alternative generation and stable-behavior distinctions | These are PI’s own Scales and Directions, not LAKA’s change columns. |
| Functions focus on Actions; Outcomes focus on States | Separation of mechanism from resulting state | LAKA adds explicit Feedback, Constraints, Value, and Failure mode roles. |
| Begin State and End State | Current-to-target state records | Embedding these in every LAKA variable is a LAKA adaptation. |
| Functional Distinctions | Test whether a proposed difference matters | The five LAKA change-level boundaries are not source doctrine. |
| Dilemmas, assumptions, and inversion | Problem-solving playbook | Real tradeoffs and constraints still require evidence; no guaranteed solution claim is adopted. |
| Innovation sequences, Ideal States, and enabling steps | Conditional future paths | Numeric forecast tracking and calibration rules are LAKA implementation additions. |
| Importance and Satisfaction | Positioning and opportunity questions | The proposed weighted LAKA rubric is separate from the source’s Opportunity Score. |

The six operating modes, 700 prompt stems, operator command vocabulary, templates, JSON schema, scoring rubric, and hypothetical support example are LAKA design material developed in this conversation/package. They are not excerpts from the book and are not independently validated.

PI treats required Outcomes as fixed within a given Scenario [PI-16]. LAKA permits purpose or success-definition changes at the Paradigm level; this is an explicit extension that requires a changed/versioned Scenario for honest comparisons.

## Claims not adopted as established facts

The source contains broad completeness, financial-performance, and other promotional or empirical claims. This packaging task did not independently verify them. They are not used to claim LAKA guarantees profits, eliminates risk, covers all possible innovations, or predicts future outcomes accurately. No medical or therapeutic claims from the book are adopted here.

An empty LAKA coordinate is a research prompt, not proof of a missing invention. A high heuristic score is not a success probability. An inferred system fingerprint is not proof of a unique cause, private intent, or personal culpability.
