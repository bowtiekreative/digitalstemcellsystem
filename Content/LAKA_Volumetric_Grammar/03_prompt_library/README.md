# Prompt library

The library contains exactly **700 unique coordinates**: 5 change levels × 10 internal variables × 14 meta-variables. The JSON and the full Markdown file contain the same 700 prompts. Each internal-variable file contains its 70 prompts. These are different views of the same library, not additional unique prompts.

Start with one concrete Scenario and one desired observable Outcome. Answer the relevant Baseline questions first. Use a focused sweep before attempting all 700. Mark unanswered, not-applicable, infeasible, and contradicted cells explicitly; never fill them with invented evidence.

The underlying axes are descriptive choices, not a proof that all innovations have been enumerated. A cell may contain several candidates. A candidate may touch many cells. Dependencies mean that arbitrary combinations need not be compatible.

## Coverage bookkeeping

Track `reviewed / 700` for a declared full-scenario sweep. Also report counts of applicable, answered, unresolved, infeasible, and not-applicable cells. Do not call reviewed coverage an Innovation Quotient, a probability of success, or a percentage of all possible ideas in the world.

## Recommended first pass

Establish all ten internal variables. Select the two or three tensions most relevant to the Outcome. Review their five change levels and the dynamic modifiers that could distinguish a useful solution. Compose only after checking that proposed states and dependencies can coexist.
